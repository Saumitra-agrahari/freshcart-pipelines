# FreshCart Data Engineering Pipelines

Data engineering repository for the "From Git to Gold" assignment.

## Project Structure
- `elt/`: FreshCart ELT notebook and SQL transformations (Snowflake)
- `iris_project/`: Mage data pipeline project (Iris classification)
- `stream/`: RabbitMQ event dispatcher and driver consumers
- `tests/`: Automated unit tests for pipeline transformers
- `report/`: Analysis, tables, and design answers
- `.github/workflows/`: CI/CD workflows (GitHub Actions)
